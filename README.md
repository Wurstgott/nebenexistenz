# Nebenexistenz

Eine App, die hilft, nebenberuflich kleine, legale Gewerbe aufzubauen, die andere führen, ohne Freunde, Familie und Freizeit aus dem Blick zu verlieren.

Live: https://wurstgott.github.io/nebenexistenz/

Bauen: `python3 src/build.py` schreibt `index.html`, `manifest.json`, `sw.js` und die Icons.

Die App erklärt und bereitet vor. Sie ersetzt keine Steuer- oder Rechtsberatung.
